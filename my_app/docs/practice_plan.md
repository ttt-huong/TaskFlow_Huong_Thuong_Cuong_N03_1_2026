# KẾ HOẠCH THỰC HIỆN BÀI TẬP: LẤY DỮ LIỆU TỪ NGƯỜI DÙNG

**Nhóm sinh viên:** Hương - Thương - Cường
**Dự án:** TaskFlow App
**Thời gian lập kế hoạch:** 12/05/2026

---

## 1. Mục tiêu bài tập
- Thực hành sử dụng `TextFormField` và các widget nhập liệu trong Flutter.
- Hiểu cách lấy dữ liệu thời gian thực (Real-time) và lấy dữ liệu theo sự kiện (Selection).
- Hoàn thành báo cáo cá nhân và báo cáo nhóm.

## 2. Phân công nhiệm vụ cá nhân (Câu 2)

| Sinh viên | Đối tượng đảm nhiệm | Loại dữ liệu | Mục tiêu cụ thể |
| :--- | :--- | :--- | :--- |
| **Nguyễn Thị Hương** | `TextFormField` | String (Văn bản) | Xây dựng ô nhập Email, lấy dữ liệu ngay khi người dùng gõ phím. |
| **Trần Văn Thương** | `DropdownButtonFormField` | String (Lựa chọn) | Xây dựng danh sách chọn Vai trò (Role), lấy giá trị được chọn từ Menu. |
| **Lê Văn Cường** | `SwitchListTile` | Boolean (Logic) | Xây dựng nút gạt Bật/Tắt thông báo, lấy giá trị True/False. |

## 3. Các bước thực hiện
1. **Bước 1 (Nhóm):** Khởi tạo màn hình thực hành `InputPracticeScreen` và cấu hình Route trong `app.dart`.
2. **Bước 2 (Cá nhân):** Mỗi thành viên code phần widget của mình vào khu vực đã phân công.
3. **Bước 3 (Nhóm):** Chạy ứng dụng trên máy ảo/thiết bị thật để kiểm tra tính năng `Get Value`.
4. **Bước 4 (Cá nhân):** Chụp ảnh màn hình kết quả và code chính để đưa vào báo cáo.
